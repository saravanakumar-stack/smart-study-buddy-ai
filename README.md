# 🎓 Smart Study Buddy AI

**An AI-powered learning assistant for 1st and 2nd-year college students.**

Smart Study Buddy AI is a Generative AI-based educational application designed to make learning easier, smarter, and more interactive. It uses Google's Gemini AI to help students understand difficult concepts, prepare study notes, practice quizzes, and organize their study schedules.

## 🚀 Features

The application provides six main learning tools:

1. **AI Notes Generator** – Generates structured study notes with headings, definitions, and examples.
2. **Concept Explainer** – Explains difficult academic concepts in simple language with easy-to-understand examples.
3. **AI Quiz Generator** – Creates multiple-choice questions (MCQs) to test students' knowledge.
4. **Important Practice Questions** – Generates useful revision and practice questions for exam preparation.
5. **Code Explainer** – Helps beginners understand programming code through simple explanations.
6. **Study Planner** – Creates personalized study schedules based on subjects and available study time.
